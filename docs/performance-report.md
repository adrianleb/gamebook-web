**Recommendations for browser testing:**
1. Use Chrome DevTools Memory profiler
2. Record baseline after initial load
3. Run automated playthrough for 30+ minutes

   - `choicesMade` array (expected linear growth)
   - Event listener leaks

**Design mitigations in place:**
- No closures capturing large state in event handlers
- Immutable state updates (no circular references)
- No dynamic imports during gameplay
- Efficient Map-based lookups for nodes/items
