## CC0 License

The CC0 (Creative Commons Zero) license is a public domain dedication that allows creators to waive all copyright and related rights. Assets under CC0:

- Can be used for any purpose (commercial or non-commercial)
- Do not require attribution (though we provide it voluntarily)
- Can be modified, distributed, and used without restriction

For more information: https://creativecommons.org/publicdomain/zero/1.0/

## Adding New Assets

When adding new audio assets:

1. Verify the license is CC0 or compatible (CC-BY requires attribution)
2. Add an entry to the appropriate section above
3. Include the source URL, author, and original filename
4. Run the validation script to ensure format compliance
